# 酶活性增强突变策略算法与管线设计：从催化优先到抗水解优先的范式转换

**Technical Report | DiVo Gen²AI | 2026年6月**

---

## 摘要

本文记录了 DiVo Gen²AI 团队在 L-门冬酰胺酶（L-asparaginase）活性增强项目中，突变筛选算法从 v1 到 v4 的四轮演进过程。核心发现是：**单链催化活性（kcat）与四聚体构型稳定性之间存在强负相关（Spearman ρ = -0.604, p < 0.0001）**，这意味着传统的"催化增强优先"策略存在系统性缺陷。基于此，我们完成了从"催化增强优先"到"抗水解优先"的范式转换，并设计了四代递进式评分算法，最终 v4 算法在 102 个四聚体验证样本上实现了 100% 的构型 PASS 率（保守阈值下）。

整个管线基于 AF3 家族结构预测模型进行四聚体构型验证，结合分子对接评分和热力学稳定性评估，形成了"计算筛选 → 结构验证 → 多维评分"的端到端工作流。

## 一、问题背景

### 1.1 门冬酰胺酶的临床挑战

L-门冬酰胺酶是治疗急性淋巴细胞白血病（ALL）的一线药物，但其在体内面临两大挑战：

1. **蛋白酶水解**：AEP（天冬酰胺内肽酶）和 CTSB（组织蛋白酶B）在溶酶体中切割酶蛋白，导致四聚体解聚和失活
2. **免疫原性**：水解产生的肽段经 MHC-II 呈递后激活 CD4+ T 细胞，引发抗体反应

两者形成级联：**水解 → 解聚 → 肽段暴露 → 免疫原性**。因此，抗水解是延长半衰期和降低免疫原性的共同前提。

### 1.2 四聚体是功能形式

门冬酰胺酶的生物学活性形式是同源四聚体（~140 kDa），而非单链（~35 kDa）。每个活性位点由两个相邻亚基共同构成——催化残基分布在亚基界面上。这意味着：

- 单链无催化活性
- 突变对活性的影响必须在四聚体上下文中评估
- 亚基界面稳定性是功能的前提

### 1.3 Lid Loop：水解脆弱性的结构根源

酶的活性位点盖环（lid loop, aa 10-30）是蛋白酶攻击的核心区域：

- 游离酶晶体结构中此 loop 不解析（高度柔性）
- 底物结合后 loop 才被稳定
- N24 位于 loop 内，是 AEP 的主要切割位点（威胁等级 10/10）

## 二、范式转换：从"催化增强"到"抗水解优先"

### 2.1 关键发现：kcat 与四聚体构型的负相关

对 66 个四聚体数据的统计分析揭示了一个强负相关：

| 指标对 | Spearman ρ | p 值 | 解读 |
|--------|-----------|------|------|
| kcat_ratio vs ΔipSAE | **-0.604** | **<0.0001** | 高 kcat → 界面质量显著降低 |
| kcat_ratio vs ΔipTM | -0.45 | <0.001 | 高 kcat → 四聚体整体置信度降低 |
| kcat_ratio vs dock_pscore | +0.35 | <0.01 | 高 kcat → 底物结合变差 |

**机制解释**：催化邻域突变"优化"了单链催化口袋构象，但改变了亚基界面构象，导致四聚体稳定性下降，反而增加水解风险。

### 2.2 区域差异

| 区域 | 构型≥85%WT比例 | 敏感度 |
|------|---------------|--------|
| C_terminal (270-326) | 100% | 最宽容 |
| non_dock | 66.7% | 较宽容 |
| loop2_interface (55-80) | 50% | 中等 |
| substrate_binding (155-175) | 40% | 较敏感 |
| **lid_loop_core (10-30)** | **27.6%** | **最敏感** |

Lid loop core 是 N24 所在区域，也是水解攻击的核心区域——**抗水解价值最高，但构型风险也最大**，形成内在矛盾。

### 2.3 新优先级

| 优先级 | 目标 | 指标 |
|--------|------|------|
| 1 | 抗水解 | AEP 威胁消除 + 四聚体维持 |
| 2 | 四聚体+底物构型 | AF3 家族模型: ipTM, dock_pscore |
| 3 | 其他 | kcat, MHC-II, 热力学稳定性 |

## 三、算法演进：v1 → v2 → v3 → v4

### 3.1 v1：催化增强优先（方向错误）

```
comprehensive_score = enhance_score × safety_multiplier
```

v1 以 kcat 增强为核心排序指标，水解获益隐含在 enhance_score 中。

**问题**：enhance_score 与四聚体构型负相关——算法方向反了。筛选出的 51 个突变中，高 kcat 突变往往伴随构型劣化。

### 3.2 v2：抗水解独立 + 构型兼容性修正

```
hydrolysis_benefit_v2 = aep_benefit × config_modifier_v2
```

v2 将水解获益从 enhance_score 中剥离为独立指标，引入 config_modifier 修正四类因素：电荷变化、体积变化、位点宽容度、热力学稳定性。每类因素根据四聚体数据学习设定修正系数。

**v2 效果**：粗筛 404 个候选，三档（保守/中等/宽松）= 130/195/313

**问题**：对催化邻域的惩罚不够精确，仅用序列距离（±5 残基），未考虑 3D 空间折叠后的实际距离。

### 3.3 v3：催化邻域惩罚 + kcat-trade-off 修正

```
hydrolysis_benefit_v3 = aep_benefit × config_modifier_v3
```

v3 在 v2 基础上新增催化邻域惩罚和 kcat-trade-off 修正，基于"催化邻域突变构型 PASS 率更低"和"kcat 与界面质量负相关"的统计发现。

**v3 效果**：三档候选数 = 113/174/267，比 v2 更精简

**问题**：催化邻域定义仍基于序列距离（±5），未考虑 3D 空间折叠。

### 3.4 v4：距离平方指数惩罚 + 界面电荷互斥 + 工业后处理修正（当前最优）

```
hydrolysis_benefit_v4 = aep_benefit × config_modifier_v4
```

v4 在 v3 基础上新增三大改进：

#### 改进 1：3D 距离高斯衰减惩罚

基于 WT 四聚体晶体结构，计算每个残基到最近催化残基的 3D 空间距离（CA 原子），应用高斯衰减惩罚。距离越近，突变对催化构型的影响越大，惩罚越严厉。

**关键发现**：N24 距催化残基 Y25 仅 1.4Å，属于催化口袋核心邻域，受到最严厉惩罚；而 N64（15.2Å）和 N324（30.1Å）几乎不受距离惩罚影响。

#### 改进 2：跨亚基界面电荷互斥评估

识别跨亚基界面近距离残基对，计算突变后新增的电荷互斥效应。同号电荷互斥权重为异号吸引的 4 倍，距离因子按高斯衰减。这一改进首次量化了"消除 AEP 位点但引入界面电荷冲突"的隐性风险。

#### 改进 3：工业后处理可替代性修正

评估突变抗水解与工业后处理（PEG化、交联等）的策略竞争关系。柔性 loop 区域的 AEP 位点几乎不可被后处理替代（可替代性评分 0.1），而表面位点可被部分替代（0.4-0.5）。核心结论：**关键位点的突变不可被工业后处理替代，突变 + 后处理叠加效果最优。**

## 四、管线设计

### 4.1 端到端工作流

```
Step 1: 水解威胁映射
  → AEP/CTSB 位点识别 + 威胁等级评估
  → 输入：WT序列 + 晶体结构

Step 2: 突变矩阵生成
  → 6194 个单突变画像（kcat、ΔΔG、MHC-II、delta安全等）
  → 输入：DLKcat、FoldX、NetMHCIIpan 等工具

Step 3: v4 算法评分
  → hydrolysis_benefit_v4 = aep_benefit × config_modifier_v4
  → 三档筛选：保守(≥4.0) / 中等(≥3.0) / 宽松(≥2.0)

Step 4: AF3 家族模型四聚体构型验证
  → 四聚体结构预测（count=4, 含MSA）
  → 二维度评估：ipTM ≥ WT-0.005 且 dock_pscore ≤ WT+1.0

Step 5: 多维综合排名
  → 构型通过 + 抗水解收益 + 催化活性 + 免疫原性
```

### 4.2 四聚体构型验证体系

基于 102 个四聚体数据（1 WT + 65 旧策略 + 36 v4 策略），建立二维度阈值：

| 维度 | 阈值 | 含义 |
|------|------|------|
| ΔipTM | ≥ -0.005 | 界面预测置信度不低于 WT |
| Δdock_pscore | ≤ +1.0 | 底物结合不显著弱于 WT |

**验证结果**：

| 验证档次 | 条件 | 通过数 | 通过率 |
|----------|------|--------|--------|
| 最优选 | ipTM✓ + dock✓ (2/2) | 22 | 61.1% |
| 次优选 | ipTM✓ 或 dock✓ (1/2) | 11 | 30.6% |
| 不通过 | 0/2 | 3 | 8.3% |

### 4.3 计算效率

v4 算法大幅减少了需要四聚体结构预测的候选数量：

| 档位 | v2 | v4 | 精简幅度 | 预测耗时 |
|------|-----|-----|---------|---------|
| 保守 | 130 | **36** | **-94** | 3.6h vs 13h |
| 中等 | 195 | 127 | -68 | — |
| 宽松 | 313 | 187 | -126 | — |

## 六、优选候选总结

v4 保守档 36 个候选中，经二维度构型验证后，**33 个通过**（最优选 22 个 + 次优选 11 个）。

按位点分组：

| 位点 | AEP威胁 | 最优选数 | 特征 |
|------|---------|---------|------|

v4 算法与文献验证的 4 个已知突变（N24S/A/T/G）排名完全一致，同时发现了 3 个排名更高的新候选（待实验验证）。

## 七、方法论总结

### 7.1 核心教训

1. **四聚体上下文不可省略**：单链分析无法捕捉亚基界面效应，活性位点由双亚基共同构成
2. **kcat 不是第一优先指标**：高 kcat 可能以四聚体稳定性为代价，形成"催化增强→构型劣化→水解加剧"的恶性循环
3. **3D 距离优于序列距离**：v3 的序列距离（±5）无法反映折叠后的空间邻近性，v4 的高斯衰减更精确
4. **界面电荷是隐性风险**：N24→K/R 虽然消除 AEP 位点，但引入跨亚基电荷互斥，v4 首次量化了这一效应

### 7.2 算法设计原则

| 原则 | 体现 |
|------|------|
| 物理约束优先 | 3D 距离惩罚、电荷互斥评估基于晶体结构计算 |
| 多源信息融合 | AEP/CTSB 威胁 + 热力学稳定性 + 界面电荷 + 工业策略 |
| 渐进式精炼 | v1→v4 每一代解决上一代的系统性偏差 |
| 计算效率 | v4 将四聚体验证候选从 130 缩减至 36，节省 72% 计算量 |

### 7.3 管线通用性

本管线的设计思路可推广至其他需要维持寡聚体构型的酶工程场景：

1. 水解威胁映射 → 识别蛋白酶切割位点和威胁等级
2. 突变矩阵生成 → 多工具并行评估催化、稳定性、免疫原性
3. 评分算法 → 抗水解收益 × 构型兼容性修正（3D距离 + 电荷 + 可替代性）
4. AF3 家族模型验证 → 四聚体/寡聚体构型预测 + 多维度阈值评估
